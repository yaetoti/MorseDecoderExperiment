# Morse Decoder

So, my friend sent me a 9 minutes Morse message. I know the code, but spent 2 hours making this program, because it's "more productive".

### Usage

- Place an audio file named `jiggleWiggle.wav` in the root folder
- Edit the delays and attack interval
- Edit symbol map if needed
- Pray that it works
